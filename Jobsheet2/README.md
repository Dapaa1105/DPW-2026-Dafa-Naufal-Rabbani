## Ringkasan
1. Folder assets/css/: Membuat folder baru yang berisi file style.css agar pengaturan tampilan visual seluruh halaman web bisa diatur dari satu tempat secara rapi.

2. Pembaruan Halaman HTML: Menghubungkan file index.html, list.html, dan tambah.html (pada folder anggota dan buku) ke file style.css supaya desain tabel, tombol, dan formulir terlihat lebih rapi dan menarik.
